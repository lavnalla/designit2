DesignIt Studio browser extension

Download:
1. Download designit-studio-extension.zip from the Studio page.
2. Extract the zip to a normal folder on your computer.

Install in Chrome or Edge:
1. Open chrome://extensions or edge://extensions.
2. Turn on Developer mode.
3. Click Load unpacked.
4. Select the extracted designit-extension folder.

Use:
1. Use right-click on an image only when the page exposes a normal image element.
2. Click Open in DesignIt.
3. Studio opens and loads that image into Source automatically.
4. Remote image links are proxied through DesignIt so sites with strict CORS rules still open in Studio.

Picker mode for blocked pages:
1. Click the DesignIt Studio extension icon for blocked pages.
2. Use the floating toolbar in the page.
3. The extension icon starts in Capture Area mode.
4. Choose Pick Image only if the page exposes a real selectable image.
5. Choose Capture Area to use the orange dashed crop box.
5. Press Esc to cancel picker mode.

Screenshot fallback:
1. Start picker mode on a page where the image cannot be directly selected.
2. Switch to Capture Area in the floating toolbar.
3. Click and drag a box around the visible product area.
4. Release the mouse to capture that area and send it to Studio as an imported source image.
